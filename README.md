**AZURA BAY — City of Glass and Gold.** An open-world crime game in the spirit of GTA 6, built from scratch in three.js: drive the lofted-body Solara GT down Strand Boulevard with the APD in pursuit, thread the Neon Row night market, get a 24-karat gold respray at Azura Customs, and read the whole city from the map. Four story missions, police response with named units, a helicopter overhead, traffic in three silhouettes, a walking crowd, a full HUD with minimap, wanted level, weapons and crew abilities — all playable with WASD in a desktop browser, no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and drive with WASD / arrow keys (R resets the car).
